# Работа Аттестация — расчёт CalcD и протоколы

Программа заменяет ручной перенос данных из Excel в старый CalcD (2012):
вставляете столбцы из листа аттестации, программа считает каждый канал
так же, как CalcD, и создаёт Word-протоколы (один документ, протоколы каналов подряд).

## Запуск

* `run.bat` — при первом запуске создаёт окружение Python и ставит
  зависимости, дальше просто открывает окно.
* `build_exe.bat` — собирает `dist\AttestIK.exe`, который работает без Python.

## Как пользоваться

1. В Excel выделите строки каналов (жёлтые столбцы или целые строки) и
   нажмите Ctrl+C. Можно сразу много каналов, хоть 1000+.
2. В программе нажмите «Вставить из буфера» (или «Открыть Excel…»).
3. Проверьте «Измерений в точке» (по умолчанию 20, как в CalcD) и нажмите
   «Рассчитать». Внизу видно подробный расчёт выбранного канала.
4. «Копировать результаты» — таблица с запятыми для вставки обратно в Excel.
5. «Создать протоколы» — один Word-файл, в нём N протоколов подряд (1–100),
   у каждого своя шапка с № из Excel, каждый с новой страницы; начиная с
   указанной строки, после создания начало сдвигается дальше.

### Какие столбцы понимает вставка

* Жёлтые столбцы: `№, KKS, Наименование, Нижняя, Верхняя, Ед., %, [вход 4–20 мА],
  действительное значение, измерение 1, измерение 2, …`. Входной сигнал
  определяется и пропускается сам. Можно начинать с KKS (без №).
* Целые строки листа A…Y, как в `К-8.xlsx` (действительное — I, измерения — J…M,
  ПИП — P, допустимая — R, ПИП/модуль — T…W).
* Отрицательные диапазоны (например −50…200 °С) и числа с запятой поддерживаются.
* Если во вставке нет погрешности ПИП и допустимой погрешности, их можно задать
  в полях «Если нет в данных».

## Расчёт

Модуль `attest/calcd.py` перенесён из `CalcD.jar` по байткоду, и результаты
совпадают с отчётом CalcD из папки `input` до последнего знака (`tests/test_calcd.py`).
Значения точки размножаются до «измерений в точке» так же, как их вводили
вручную: одно значение — 20 раз; два — первое 10 раз (прямой ход), второе 10 раз
(обратный ход).

Особенности CalcD, которые сохранены как есть:

* замена грубых промахов (критерий из V1) на результат не влияет — CalcD
  сразу пересчитывает ряд заново;
* дисперсия D считается не по всем измерениям, а только по последнему
  значению прямого и обратного хода;
* в регрессии диапазон считается от min(0, xd) до max(0, xd).

Погрешность ЭТ ИК = max(|gh|, |gl|), общая = √(ПИП² + ЭТ ИК²),
«Годен», если общая ≤ допустимой.

## Шаблон протокола

Пока шаблона нет, создаётся временный образец. Свой шаблон — обычный .docx,
в нём пишутся метки:

| Метка | Что подставляется |
|---|---|
| `{{№}}`, `{{KKS}}`, `{{НАИМЕНОВАНИЕ}}` | номер, KKS, наименование |
| `{{НИЖН}}`, `{{ВЕРХН}}`, `{{ЕД}}`, `{{ДИАПАЗОН}}` | диапазон |
| `{{ПИП}}`, `{{ПОГР_ПИП}}`, `{{МОДУЛЬ}}`, `{{ПОГР_МОДУЛЯ}}` | ПИП и модуль |
| `{{a1}}`, `{{a2}}`, `{{b1}}`, `{{b2}}`, `{{gh}}`, `{{gl}}` | коэффициенты CalcD |
| `{{ЭТ_ИК}}`, `{{ОБЩАЯ}}`, `{{ДОПУСТ}}`, `{{РЕЗУЛЬТАТ}}` | погрешности и вывод |
| `{{ДАТА}}`, `{{ЗАМЕТКИ}}` | дата создания, заметки |

Строка таблицы с метками точки повторяется для каждой точки:
`{{т.№}}`, `{{т.%}}`, `{{т.вход}}`, `{{т.xd}}`, `{{т.изм}}`, `{{т.ds}}`,
`{{т.dh}}`, `{{т.dl}}`, `{{т.верх}}`, `{{т.низ}}`.
