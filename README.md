# Plus Ultra

Программа для метрологической аттестации измерительных каналов (ИК): берёт
каналы из Excel, считает коэффициенты a1, a2, b1, b2, gh, gl и создаёт Word-документы
по образцам заказчика — протоколы и перечень ИК с градуировочными таблицами.

## Скачать

* [PlusUltra.exe](https://github.com/geridovich/rabota-attestaciya/raw/main/release/PlusUltra.exe) —
  готовая программа для Windows Vista/7/8/10/11, 32- и 64-битных. Python не нужен,
  запуск двойным щелчком. Если Windows покажет «Система Windows защитила ваш
  компьютер», нажмите «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

1. «Открыть Excel…», перетащить файл Excel в окно программы или скопировать строки каналов в Excel (Ctrl+C) и нажать
   «Вставить из буфера». Каналов может быть сколько угодно.
2. Справа заполнить:
   * «Аттестация ИК» — окончание заголовка протокола («…метрологической аттестации ИК
     САУГ КА-4 ТЭЦ-17»);
   * «Перечень ИК» — окончание заголовка перечня («Перечень измерительных каналов
     ПТК САУГ КА-4 Выборгской ТЭЦ (ТЭЦ-17)»);
   * исполнителя;
   * даты протоколов: до 15 диапазонов «с № по № — дата», например 1–10 → 07.07.2026,
     11–40 → 08.07.2026. № протокола = № канала из Excel.
3. «Протоколы» — один Word-файл, в нём N протоколов подряд (1–3000), каждый с новой
   страницы; «Только выделенные» — по выделенным строкам; «Перечень» — перечень всех
   каналов и градуировочные таблицы (Приложение Г).
4. Вкладка «Настройки»: цветовая палитра (Batman, Superman, Spider-Man, Iron Man, Hulk),
   измерений в точке, папка для документов. Кнопка «♪» включает и выключает музыку.

## Полечить файл

Кнопка рядом с «Открыть Excel…». Приводит открытый файл к одному виду (как ТА-6) и
сохраняет копию «… (вылечено).xlsx», дальше программа работает с ней:
столбцы по местам (сдвинутые, без «№», диапазон текстом), единица измерения из строки
ниже, заметки из столбца KKS — в «Заметки», пустые заготовки удаляются, числа-текст
становятся числами, переносы строк в названиях убираются, формулы I, N, O, Q, R, S
ставятся заново. В окне показывается, что именно исправлено.

## Magic

Круглая чёрная кнопка «magic» (под ней ползунок 5–60 %) работает с файлом, открытым
кнопкой «Открыть Excel…». На листе с измерениями она заполняет пустые «Измеренное
значение выходного сигнала» (J–M, одинаковые значения) и сохраняет копию
«… (magic).xlsx» рядом с исходным файлом. Заданная доля каналов получает случайную
ненулевую погрешность, остальные — точные значения. Погрешность выбирается так, чтобы
по формулам листа канал остался годным: O ≤ √(R² − P²) с запасом 5 %
(R — допустимая, при отсутствии 1,1·√(P² + W²)). Каналы, где измерения уже есть,
не трогаются. Каждое нажатие даёт новый случайный набор.

## Какие столбцы Excel используются

Лист как в образце: № (A), KKS (B), наименование (C), нижняя и верхняя граница (D, E),
ед. изм. (F), % (G), входной сигнал (H), действительное значение (I), измерения 1–4 (J–M),
допустимая погрешность ИК (R или X), ПИП (T) и его погрешность (U или P), модуль (V) и его
погрешность (W). Можно вставлять и только жёлтые столбцы — программа определит их сама.

В протоколе «Меньшее» — первая половина измерений точки, «Большее» — вторая
(1 столбец измерений → одно значение в обоих рядах; 4 столбца → J, K и L, M).

## Расчёт

`attest/calcd.py` — расчёт старой программы CalcD (2012), перенесённый по байткоду;
совпадает с CalcD до последнего знака (`tests/test_calcd.py`).

## Градуировочные таблицы

* Сигналы 4–20 мА — значения входного сигнала из столбца H.
* Термосопротивления — сопротивление по НСХ: медь 50М/100М как в образце заказчика
  (α = 0,00426), платина 100П и Pt100 по ГОСТ 6651-2009. Тип берётся из столбца ПИП.
* Термопары (ТХА, ТХК, ТП…) в таблицы не попадают, как и в образце.
